# Vamtech Technologies - Official Enterprise Website

Built with **Next.js 14 (App Router)**, **TypeScript**, and a customized **Glassmorphic Gradient Design System** aligned with the Vamtech brand identity.

---

## 🌟 Key Features

1. **Exact Brand Identity Integration**:
   - High-fidelity vector SVG brand logo with coral (`#FF5E3A`), magenta (`#E01A8A`), purple (`#7B2CBF`), and azure blue (`#0066FF`) gradients.
   - Luxury obsidian dark mode backdrop with smooth radial light fields.

2. **Stakeholder-Driven Navigation (Audience Lens)**:
   - Dynamic tab selector tailored for **CTOs / Technical Evaluators**, **Business Leaders / Buyers**, **Procurement / Risk Leads**, and **Founders / Investors**.

3. **Engineering Capabilities Hub (`/services`)**:
   - Comprehensive breakdowns for **Custom Enterprise Software**, **Cloud Modernization & DevOps**, **AI Engineering & RAG Workflows**, and **High-Performance Web/Mobile Platforms**.

4. **Outcome-Centric Case Studies (`/case-studies`)**:
   - Structured **Problem $\rightarrow$ Engineering Strategy $\rightarrow$ Measurable ROI Metrics** for Supply Chain Logistics, FinTech Settlement, and Clinical HealthTech.

5. **Transparent Pricing & Engagement Models (`/pricing`)**:
   - Three clear models: **Fixed-Scope MVP Sprint**, **Dedicated Engineering Squad**, and **Fractional CTO Retainer**.
   - Includes the **Interactive Project Scope & Budget Estimator**.

6. **Enterprise Security & Compliance Center (`/security`)**:
   - SOC 2 Type II alignment, TLS 1.3 encryption, GDPR compliance, and automated SAST/SCA security pipeline disclosures.

7. **Interactive Project Intake & Scheduling (`/contact`)**:
   - Full interactive client intake form with scope selector, budget tiers, celebratory particle feedback, and instant meeting booking simulator.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

---

## 📦 Deployment

Deploy to **Vercel** with one click or containerize with **Docker** for AWS/GCP Kubernetes clusters.
